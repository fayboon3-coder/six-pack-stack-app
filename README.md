# Six-Pack Stack app

The coaching app for Six-Pack Stack clients (Expo / React Native + Supabase).

- `app/` screens: sign-in, Today, Train, Plan, Progress, Boon, workout, Sunday check-in
- `src/` theme, Supabase client, program logic, workout logging (works offline)
- `supabase/` database schema (row level security: clients see only their own data)
